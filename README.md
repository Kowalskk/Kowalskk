### What I'm building now

**[Ktrade](https://github.com/Kowalskk/ktrade-showcase)** · web trading terminal for Elysium (HyperEVM L2) · live

A terminal I took from idea to real trading on my own. Market discovery with new pairs and trending tokens, token pages with charts and trades, a wallet tracker, a portfolio and a live feed of launches and alerts. Every order is simulated on-chain before it is sent, with spending caps, a kill switch and a closed list of supported venues. It started in paper mode and moved to real execution in phases.

![Ktrade Pulse](https://raw.githubusercontent.com/Kowalskk/ktrade-showcase/main/img/pulse.png)

The code is private because it holds wallet custody. A read-only guest demo is available on request.

- I build what I need as a trader. Most of these started because the tool I wanted didn't exist.

- I write down what the chain proves and what I'm inferring, and keep the two apart.
